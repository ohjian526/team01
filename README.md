# team01
프로젝트 소개
- 네이버 데이터랩 검색어 트렌드 API를 활용하여 디저트(탕후루, 두쫀쿠, 한정선, 고디바모찌)의 세대교체 주기와 관심도 변화를 분석하는
Streamlit 웹 애플리케이션입니다.
팀원: 강은채(), 오지안(202604181), 전혜린()
실행방법: streamlit run app.py
사용 라이브러리- 데이터 수집: urllib, 데이터 처리: json, pandas, 웹 애플리케이션 및 시각화: streamlit
